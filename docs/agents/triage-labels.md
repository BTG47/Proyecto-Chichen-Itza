# Etiquetas de triage

Los skills hablan en términos de cinco roles canónicos de triage. Este archivo relaciona esos roles con las etiquetas reales que usa el issue tracker de este repo.

| Etiqueta en mattpocock/skills | Etiqueta en nuestro tracker | Significado                                     |
| ----------------------------- | --------------------------- | ----------------------------------------------- |
| `needs-triage`                | `needs-triage`              | El responsable debe evaluar este issue          |
| `needs-info`                  | `needs-info`                | En espera de más información de quien lo reportó |
| `ready-for-agent`             | `ready-for-agent`           | Totalmente especificado, listo para un agente   |
| `ready-for-human`             | `ready-for-human`           | Requiere implementación humana                  |
| `wontfix`                     | `wontfix`                   | No se va a atender                              |

Cuando un skill mencione un rol (p. ej. "aplica la etiqueta de listo para agente"), usa la etiqueta correspondiente de esta tabla.

Edita la columna "Etiqueta en nuestro tracker" para que coincida con el vocabulario que realmente uses.
